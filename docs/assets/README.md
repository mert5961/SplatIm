# Documentation assets

This directory contains media intentionally selected for maintained documentation.

The `pipeline/` photos are source-capture examples used by the root README to explain orbit coverage. They are not segmentation masks, processed frames, splat renders, model outputs, or job artifacts.

Keep all runtime-generated media in the ignored output or research locations. Do not copy generated masks, videos, renders, caches, checkpoints, arrays, or 3D outputs into this directory.
